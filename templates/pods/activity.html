Pod Member Roster with Associated Profiles

Combines records from pod_membership, auth_user, profile_profile, and pod_pod using Django ORM's select_related(). This performs an INNER JOIN and LEFT OUTER JOIN in PostgreSQL, allowing member records, user account credentials, and student profile metadata to be retrieved in a single query.

Main Table: pod_membership (Foreign Key: user_id, pod_id)
Joined Tables: auth_user (Primary Key: id), profile_profile (Foreign Key: user_id), pod_pod (Primary Key: id)
Relationship: Many-to-One (Membership → User), One-to-One (User → Profile), Many-to-One (Membership → Pod)
Django ORM Code: PodMembership.objects.filter(pod=pod, status="active").select_related("user", "user__profile", "pod")

Part 2: SQL SUBQUERY Implementation

Verified Daily Check-Ins via Nested Subquery

Filters active pod members by checking whether their user_id exists in the set of users who completed a check-in record for today's date ({{ today_display }}). Implemented using Django's Subquery() expression, this compiles to an outer SQL query with a nested WHERE user_id IN (SELECT user_id FROM home_dailycheckin WHERE date = ...).

Inner Query: DailyCheckIn.objects.filter(date=today).values("user_id")
Outer Query: PodMembership.objects.filter(pod=pod, status="active", user_id__in=Subquery(inner_subquery))
Condition: pod_membership.user_id IN (SELECT home_dailycheckin.user_id WHERE date = '{{ today|date:"Y-m-d" }}')

Direct Supabase PostgreSQL Verification

To verify these records directly in Supabase during the video demonstration:

1. Table Editor Inspection:

  • Open Table Editor → pod_membership: note pod_id and user_id foreign keys.
  • Open Table Editor → profile_profile: note user_id and nickname columns.
  • Open Table Editor → home_dailycheckin: note user_id and date records.

2. Supabase SQL Editor Verification Query:

-- 1. Test SQL JOIN in Supabase SQL Editor:
SELECT 
    pm.id AS membership_id,
    u.username,
    prof.nickname,
    p.name AS pod_name,
    pm.role,
    pm.status
FROM pod_membership pm
INNER JOIN auth_user u ON pm.user_id = u.id
LEFT JOIN profile_profile prof ON u.id = prof.user_id
INNER JOIN pod_pod p ON pm.pod_id = p.id
WHERE pm.status = 'active';

-- 2. Test SQL SUBQUERY in Supabase SQL Editor:
SELECT 
    pm.id,
    u.username,
    prof.nickname
FROM pod_membership pm
INNER JOIN auth_user u ON pm.user_id = u.id
LEFT JOIN profile_profile prof ON u.id = prof.user_id
WHERE pm.status = 'active'
  AND pm.user_id IN (
      SELECT user_id 
      FROM home_dailycheckin 
      WHERE date = CURRENT_DATE
  );
